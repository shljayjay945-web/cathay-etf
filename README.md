# 國泰投信 人氣 ETF 與熱門基金量化投資分析系統
> **Taiwan Cathay Fund & ETF Quantitative Analysis System**  
> 跨界績效天梯 ✕ 填息回測透視 ✕ 產業純度穿透 ✕ 手機行動卡片流

本系統專為投資人打造，自動逆向對接台灣國泰投信官方微服務 API，整合 **34 檔旗艦人氣 ETF、同業重量級巨頭（0050、0056、00919、00679B）與熱門主動型基金**，進行跨界量化回測與互動視覺化分析。

---

## 🌟 核心功能特色

1. **🏆 跨界綜合績效天梯 (Tab 1)**
   - 打破 ETF 與共同基金壁壘，提供近 1 月、3 月、6 月、1 年、2 年、3 年、5 年嚴謹回測排行榜。
   - 支援「全部標的」、「自選追蹤」、「國泰主力」、「高股息擂台」、「市值型」、「債券防守」多維度快速篩選。
   - 遵循台股標準色彩規範（**紅漲 🔴 / 綠跌 🟢**）。

2. **💰 歷次配息與填息天數回測 (Tab 2)**
   - 最新每期配息金額、年化殖利率、近 1 年累計配息總額。
   - 精算除息交易日後之「平均填息交易天數」與「歷史填息成功率」。
   - 官方歷次除息紀錄彈窗，穿透「54C 股利所得」與「收益平準金」拆解比例。

3. **🧩 投資組合與持股穿透透視 (Tab 3)**
   - 獨家「產業智能分類引擎」，萃取台積電佔比、科技電子、金融保險、傳統產業純度。
   - 官網同款 Top 10 核心成分股權重長條圖（附即時市價、漲跌幅、本益比與持股市值）。

4. **⚠️ 法定 RR 投資風險評估指南 (Tab 4)**
   - 中華民國投信投顧公會法定 RR1 至 RR5 風險等級醒目徽章。
   - 附資產配置指南（年輕衝刺期、中壯平衡期、退休樂活期）。

5. **📱 手機端極致體驗（免左右橫滑）**
   - 導入「直向行動資訊卡片流 (Mobile Card View)」，單手上下滑動一目了然。
   - 支援「📱 行動資訊卡片」與「📊 完整比較大表」雙模式一鍵切換。

## 🚀 本地快速啟動

```bash
# 1. 抓取最新淨值、持股與配息數據
python cathay_fund_analysis.py

# 2. 編譯生成現代化 HTML5 互動儀表板
python build_html_dashboard.py

# 3. 雙擊一鍵更新並在瀏覽器查看
一鍵更新與開啟.bat
```
